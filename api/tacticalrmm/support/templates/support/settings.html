Screen previews

{% if screen_previews %}On{% else %}Off{% endif %}
{% csrf_token %}

Pictures show up in the session list and on each session’s General tab, so you can see what’s happening before you join. Each one is a single frame of the remote desktop, taken only while someone has this console open: every 20 seconds for the session you have open, and about once a minute for the rest of the list. Pictures are kept in the server’s cache for up to 10 minutes, not in the database. A Mac needs the same Screen Recording permission as joining.
